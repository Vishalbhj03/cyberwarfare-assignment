# DevOps Project Submission

This project demonstrates the setup of a secure Linux server, deployment of a Docker-based web application, monitoring of container resources, implementation of access control, and firewall configuration.

## Tasks Covered
- Task 1: SSH Setup with Key-based Authentication
- Task 2: Docker Installation and Application Deployment
- Task 3: Container Monitoring using Script and Cron
- Task 4: Secure Log Access using User Permissions
- Task 5: Firewall Configuration using UFW

Each task is explained in its respective folder with commands and configurations.
